# BDS-B1I-B1C-Joint-Acquisition

Dataset Availability

A deep-space weak-signal dataset based on a Moon Transfer Orbit (MTO) scenario at approximately 380,000 km is publicly released. The dataset contains digital intermediate-frequency (IF) data of the following GNSS signals:
- BeiDou B1I
- BeiDou B1C
- GPS L1 C/A

The dataset covers a range of carrier-to-noise density ratios (C/N₀) from 3 to 20 dB-Hz. It can be used for GNSS weak-signal acquisition research, algorithm validation, and performance evaluation in deep-space environments.
